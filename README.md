# Pavel Hu — Here, then gone.

Documentary photography portfolio. 62 photographs, four chapters.

Website: https://pavelllam.github.io/
Repository: https://github.com/Pavelllam/pavelllam.github.io

## Publishing

This is a complete static website. No installation or build step is required.
The public repository `Pavelllam/pavelllam.github.io` serves the GitHub user site.
Under Settings → Pages, select “Deploy from a branch”, choose the main branch
and /(root), then save. Keep the .nojekyll file in the repository root.

Upload the contents of this directory at the repository root. Updates to the
main branch publish to https://pavelllam.github.io/ after GitHub Pages deploys.
Navigation and local assets use relative URLs. Canonical and social sharing
metadata point to the live GitHub Pages address.

## Contents

- index.html, style.css, app.js: portfolio layout and interactions
- photos.js: photograph descriptions and grouping
- images/: optimized photographs and thumbnails
- fonts/: self-hosted typefaces and their license files
